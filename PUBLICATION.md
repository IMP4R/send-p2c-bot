# send_p2c_bot — исходники для ознакомления

- Исходный снимок, не готовая установка. Runtime и платежи не проверялись.

## Подготовка
Настройте собственные токены, API credentials, admin IDs, каналы и адреса сервисов. Очищенные значения в коде пустые, 0 или REPLACE_WITH_YOUR_VALUE. Для Python используйте requirements.txt при наличии; для TypeScript — package.json. Прочитайте исходный README, если он включён. Некоторые исторические зависимости и данные требуют самостоятельной подготовки.

## Состав
Исключены .env, базы, сессии, cookies, логи, backup, данные пользователей, рабочие скриншоты, дампы исходников и operational-скрипты. Включены код и небольшие исходные README. Возможные собственные изображения/баннеры исключены: замените своими. Оригиналы не изменены. Секреты и идентификаторы заменены только в архивной копии.

## Права
Этот снимок не назначает новую лицензию. Существующие upstream-лицензии сохраняют силу; зависимости устанавливаются отдельно и принадлежат своим авторам.
