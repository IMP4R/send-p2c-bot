# send_p2c_bot

Telegram P2C-интеграция: API-клиент, WebSocket, авторизация и QR-коды.

## Состав

- `.env.example`
- `PUBLICATION.md`
- `send_p2c_bot`/

## Подготовка и запуск

Манифесты зависимостей в этой копии:
- [send_p2c_bot/requirements.txt](send_p2c_bot/requirements.txt)

Переменные конфигурации перечислены в `.env.example`; используйте только собственные ключи и аккаунты. Не коммитьте заполненный `.env`.

Не импортируйте и не запускайте незнакомые модули автоматически: возможны сетевые запросы, платежные операции и другие внешние эффекты. Отсутствующие данные, сервисы и конфигурацию нужно подготовить самостоятельно.

## Ограничения снимка

- Исходный снимок, не готовая установка. Runtime и платежи не проверялись.
- При оформлении репозитория приложение не развёртывалось, платежи и внешние API не запускались; тесты не перепроверялись.
